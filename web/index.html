参数说明

除 data 外均有合理默认
参数说明默认
icon左侧图标 URL，服务端抓取后内联为 data URI；单色 SVG 自动补白—
text中间文字，最长 40 字符；留空则该列不渲染—
data右侧数值来源 URL；留空时整列省略—
query简化 JSONPath：$.a.b、$.list[0].name自动取 message / value / total
formatcomma / plain / compact / timecomma
ibg lbg rbg图标 / 文字 / 数值三列底色，命名色或 #rgb、#rrggbb#555555 · #555555 · #4caf50
h r高度 16~32 px（字号按比例缩放）、圆角 0~h/220 · 3
gloss0 关闭顶部高光开启

取数失败时仍返回 HTTP 200，右侧显示 n/a —— 避免 README 出现破图； 该响应带 no-store，下次请求立即重试。
